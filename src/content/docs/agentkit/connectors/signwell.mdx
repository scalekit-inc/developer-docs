## What you can do

Connect this agent connector to let your agent:

- **Send validate bulk, reminder, document** — Validate a bulk send CSV file before creating the bulk send
- **Update template, recipients, authentication** — Update an existing document template
- **List webhooks, bulk sends** — List all webhook subscriptions configured in the account
- **Get template, nom151 certificate, me** — Get a document template and all associated template data including placeholders and fields
- **Delete webhook, template, document** — Delete a registered webhook callback URL
- **Create webhook, template, document from template** — Register a webhook callback URL to receive document lifecycle events (sent, viewed, signed, completed, declined, etc.)
