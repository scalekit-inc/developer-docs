## What you can do

Connect this agent connector to let your agent:

- **Update project, project settings, project member** — Updates a project's (space's) name
- **Get project settings, project member, doc item** — Retrieves the sharing and access settings for a project
- **Lookup group items** — Given the ID of any item that belongs to a group, returns all items that are part of that same group on the board
- **Delete doc item, team, item** — Deletes a doc format item from a Miro board
- **Create doc item, shape, embed** — Creates a doc format item (a native markdown text block) on a Miro board
- **List board members, tags, mindmap nodes** — Returns a list of members on a Miro board
