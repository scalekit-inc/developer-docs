## What you can do

Connect this agent connector to let your agent:

- **List workflow teams, tags, sms message** — Retrieve active workflow teams from Salesforce Marketing Cloud's Approvals Hub REST API (GET /hub/v1/workflowteams/&#123;objecttype&#125;)
- **Delete workflow team user, tag, sms keyword** — Permanently remove a user's assignment from a specific role instance on a workflow item in Salesforce Marketing Cloud, using the Approvals Hub REST API (DELETE /hub/v1/workflowitems/&#123;workflowItemId&#125;/roles/&#123;workflowRoleInstanceId&#125;/Users/&#123;userId&#125;)
- **Create workflow team user, tag, sms keyword** — Assign a user to a specific role instance on a workflow item in Salesforce Marketing Cloud, using the Approvals Hub REST API (POST /hub/v1/workflowitems/&#123;workflowItemId&#125;/roles/&#123;workflowRoleInstanceId&#125;)
- **Transition workflow item** — Transition a workflow item's state in Salesforce Marketing Cloud, using the Approvals Hub REST API (POST /hub/v1/workflowitems/&#123;workflowItemId&#125;/transitions)
- **Queue sms mo message, sms contact import** — Queue a simulated mobile-originated (MO) message on your MobileConnect short code, primarily used to test keyword flows and double opt-in journeys without needing an actual mobile device to text in
- **Get sms mo message history, sms mo message delivery, sms message history** — Retrieve the full interaction history of a queued mobile-originated (MO) message, via GET /sms/v1/queueMO/history/&#123;tokenId&#125;
