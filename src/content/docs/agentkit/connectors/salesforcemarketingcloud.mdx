## What you can do

Connect this agent connector to let your agent:

- **Validate address email, file transfer location, journey** — Validate an email address's syntax and deliverability using Marketing Cloud's Address Verification API
- **Create approval item, asset category, asset** — Create an approval item and its associated workflow item in Salesforce Marketing Cloud via the Approvals API
- **Get approval item, approval settings, asset category** — Retrieve a single approval item by its unique ID from Salesforce Marketing Cloud's Approvals v2 REST API
- **List approval item roles, approval items, asset category** — List the roles defined for a given Approvals v2 item and the users assigned to each role, via GET /hub/v1/approvals-v2/&#123;id&#125;/roles on Salesforce Marketing Cloud's Approvals REST API
- **Delete asset category, asset, automation** — Permanently delete a Content Builder category (folder) from Salesforce Marketing Cloud by its numeric category ID
- **Update asset category, asset, automation** — Rename or move a Content Builder category (folder) in Salesforce Marketing Cloud
