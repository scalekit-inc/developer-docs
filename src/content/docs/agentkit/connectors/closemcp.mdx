## What you can do

Connect this agent connector to let your agent:

- **Update draft email, custom object instance, call task** — Update an existing draft email
- **Instances find custom object, find custom activity** — Find a lead's custom object instances
- **Tasks find call, find** — Find call tasks based on various filters
- **Fetch meeting transcript, custom object instance, call task** — Fetch a meeting's Notetaker transcript(s) by meeting activity ID
- **Delete custom object instance, call task, task** — Permanently delete an existing custom object instance
- **Labels customized builtin** — Return the customized builtin labels
