## What you can do

Connect this agent connector to let your agent:

- **Update media item, album** — Update the description of a media item this app created or uploaded — the only field the Google Photos API allows changing on a media item
- **Search media items** — Search this app's media items by album, date range, content category, media type, or favorite status — Google removed access to a user's full pre-existing Photos library in March 2025, so results are limited to media this app itself created or uploaded
- **List picker media items, media items, albums** — Retrieve the photos and videos the user picked during a Google Photos Picker session (from create_picker_session)
- **Get picker session, media item, album** — Check the status of a Google Photos Picker session created by create_picker_session
- **Delete picker session** — Delete a Google Photos Picker session, e.g
- **Create picker session, album, batch** — Start a new Google Photos Picker session, which lets the connected user pick any photos or videos from their FULL Google Photos library (unlike the other tools in this connector, which are restricted to app-created content only) and hand just those items to this app
