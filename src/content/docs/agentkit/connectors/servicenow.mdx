## What you can do

Connect this agent connector to let your agent:

- **Update user group, sc task, user** — Update fields on an existing user group in ServiceNow, such as its name, description, manager, or active status
- **List sc task, user role, user** — Retrieve a list of catalog fulfillment tasks (sc_task) from ServiceNow, optionally filtered with an encoded query such as `request_item=<sys_id>` to scope to one Requested Item
- **Get sc task, sc req item, knowledge base** — Retrieve a specific catalog task (sc_task) by its sys_id
- **Create sc task, user group, user** — Create a fulfillment task (sc_task) for a specific Requested Item in ServiceNow Service Catalog
- **Resolve problem, incident** — Resolve a problem by setting its state to Closed/Resolved (104) and recording the permanent fix
- **Error problem mark known** — Mark a problem as a known error by setting its state to Known Error (102) once the root cause has been identified
