## What you can do

Connect this agent connector to let your agent:

- **Create temporary attachment, request type, request comment** — Upload a file to a service desk as a temporary attachment
- **List sla information, service desks, service desk request types** — Retrieve all SLA (Service Level Agreement) records for a Jira Service Management customer request
- **Get sla information, service desk, request type property** — Retrieve the details of a single SLA (Service Level Agreement) metric on a Jira Service Management customer request, identified by the SLA metric ID
- **Remove service desk organization, service desk customers, request participants** — Remove an organization from a service desk
- **Add service desk organization, service desk customers, request participants** — Add an organization to a service desk, granting members of that organization access to raise and view requests on the service desk's portal
- **Unsubscribe request** — Unsubscribe the authenticated user from notifications on a customer request
