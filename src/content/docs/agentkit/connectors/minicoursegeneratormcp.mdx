## What you can do

Connect this agent connector to let your agent:

- **Whoami records** — Returns the MCG account this connection is authenticated as (user id, email, shop id)
- **Upload video, scorm** — Host a video on Vimeo through MCG (server-side — no Vimeo account needed) for a lesson `video` block
- **Update section, module, lesson** — Rename a Section
- **Delete section, module, lesson** — Delete a Section and its Lessons
- **Create section, module, lesson** — Add a Section to an existing Module
- **Push module** — Create one complete Module (sections + lessons) from a `kind: Module` YAML spec
