## What you can do

Connect this agent connector to let your agent:

- **Media upload, download** — Upload a file (up to 200MB) as a Google Chat attachment, to be referenced when sending a message
- **Update user availability, space read state, space notification setting** — Update the authenticated user's custom status message in Google Chat, with an optional emoji and expiration
- **Space setup, find direct message** — Create a Google Chat space and add specified members to it in a single call
- **Search spaces, messages** — Search for spaces across a Google Workspace organization using domain-wide admin access
- **Section reposition** — Change the sort order of a section in Google Chat's navigation panel, moving it to an absolute position or to the start or end of the section list
- **Message replace** — Update an existing Google Chat message using the PUT-based update endpoint
