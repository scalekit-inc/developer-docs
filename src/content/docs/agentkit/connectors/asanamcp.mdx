## What you can do

Connect this agent connector to let your agent:

- **Search objects internal, tasks preview, tasks** — DEPRECATED; DO NOT USE
- **Confirm save task changes, save project changes** — DEPRECATED; DO NOT USE
- **Event log widget** — DEPRECATED; DO NOT USE
- **Get task stories, project internal, workspace agents** — Get the full activity feed (stories) for a task by ID
- **Create task preview v4, task confirm, project preview v3** — Generates a visual preview of a single task and asks for confirmation before creation
- **Update tasks** — Update one or more tasks in a single operation
