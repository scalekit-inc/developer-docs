## What you can do

Connect this agent connector to let your agent:

- **Update survey questions, survey name, feedback** — Replace the question set of an existing survey while keeping its name
- **Feedback tag, merge** — Add or remove a tag on a feedback post
- **List votes, users, topics** — List all votes for a feedback post
- **Get voters, user segment, user** — Get the list of users who voted on a feedback post (with vote direction)
- **Delete tag, feedback, comment** — Permanently delete a workspace-level tag
- **Create tag, survey, feedback** — Create a new workspace-level tag
