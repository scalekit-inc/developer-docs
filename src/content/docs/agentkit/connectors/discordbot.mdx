## What you can do

Connect this agent connector to let your agent:

- **Update invite target users, lobby message moderation metadata, application role connection metadata** — Update the users allowed to see and accept an existing invite
- **Search threads, guild messages, guild members** — Search for threads in a forum or media channel by name, applied tags, archive state, and other filters
- **Invite resolve** — Resolve a Discord invite code to its invite object, including the associated guild, channel, and inviter
- **List sticker packs, entitlements, current user guilds** — Retrieve all default Discord sticker packs (the packs available to Nitro subscribers), including each pack's name, description, stickers, cover sticker, and banner asset
- **Get guild widget png, guild widget, guild template** — Retrieve a PNG image widget for a Discord guild — a visual banner that can be embedded on external websites to show live member counts and an invite link
- **Create guild sticker, webhook, test entitlement** — Create a new sticker for the guild
