## What you can do

Connect this agent connector to let your agent:

- **Update calendar, shared calendar event, focused inbox override** — Rename or recolor an existing calendar
- **Send draft message, message from shared mailbox, message** — Send an existing draft message, such as one created with Create Draft Message
- **Message reply all, forward, copy** — Immediately reply to the sender and all recipients of a message, without creating a draft first
- **Delete permanently, shared calendar event, message attachment** — Permanently delete a message, bypassing the Deleted Items folder entirely
- **Folder move mail, copy mail** — Move a mail folder, along with its contents and any child folders, under another folder
- **List event attachments, child folders, shared todo tasks** — List all attachments on a specific calendar event
