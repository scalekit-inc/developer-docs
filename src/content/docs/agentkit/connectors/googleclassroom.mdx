## What you can do

Connect this agent connector to let your agent:

- **Get user profile, topic, teacher** — Retrieve a single user's Google Classroom profile by numeric ID, email address, or 'me'
- **List topics, teachers, students** — List the topics in a Google Classroom course that the requester is permitted to view
- **Patch topic, student submission, student group** — Update the name of an existing Google Classroom topic
- **Delete topic, teacher, student group member** — Permanently delete a topic from a Google Classroom course
- **Create topic, teacher, student group member** — Create a new topic (organizational label) in a Google Classroom course
- **In student submission turn** — Turn in a student submission for grading, as the student who owns it
