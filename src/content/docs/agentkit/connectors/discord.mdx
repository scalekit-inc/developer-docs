## What you can do

Connect this agent connector to let your agent:

- **Update current user application role connection** — Updates and returns the application role connection for the current user and the given application
- **Send lobby message** — Send a message to a Discord lobby
- **List sku subscriptions, guild channels, my guilds** — Retrieve all subscriptions containing a given SKU, filtered by user
- **Lobby link channel to, leave** — Link an existing guild text channel to a Discord lobby, or unlink any currently linked channel by omitting channel_id
- **Get sku subscription, lobby messages, guild application command permissions** — Retrieve a single subscription for a SKU by its ID
- **Permissions edit application command** — Edit the permissions for a specific application command in a guild
