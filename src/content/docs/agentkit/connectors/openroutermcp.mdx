## What you can do

Connect this agent connector to let your agent:

- **Skills view** — Retrieve a curated OpenRouter best-practice recipe (an Agent Skill) by name
- **Send message, feedback** — Chat with a model and get its plain-text response, to test a prompt or compare models without leaving the editor
- **Search docs** — Search the full OpenRouter documentation to answer "how do I…" questions with correct, current API usage
- **Ping records** — Health-check tool that verifies the MCP connection is alive
- **List task classifications, providers, models** — See what OpenRouter traffic is actually used for: a market-share breakdown by task type (code generation, web search, summarization, ...) over a trailing window, each with its top models by usage, plus macro-category (Code, Data, Agent, General) aggregates
- **Get model, generation, credits** — Get full details for one model by author/slug (supports :variant suffixes and slug aliases) without fetching the whole catalog
