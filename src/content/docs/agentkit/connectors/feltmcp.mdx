## What you can do

Connect this agent connector to let your agent:

- **I who am** — Get information about the current user and workspace they are logged into
- **Annotations upsert** — Create or update lightweight markup annotations on a map — pins, notes, sketched shapes and lines
- **Map upload contents to, share, render** — Add Geo data to the map as a new layer by including its contents inline as raw text (no file upload)
- **Update map, layer properties, layer group properties** — Update a map's title, basemap, zoom level, or basemap label visibility
- **Visibility set** — Show and/or hide layers, layer groups, and legend items (categories or class breaks)
- **Interaction set layer group** — Set how a layer group's layers are toggled in the legend
