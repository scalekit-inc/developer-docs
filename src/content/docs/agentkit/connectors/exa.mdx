## What you can do

Connect this agent connector to let your agent:

- **Update webset** — Update an existing Exa Webset's metadata or external reference ID
- **List webset monitors, websets, webset items** — List Monitors, which keep a Webset continuously refreshed on a schedule via a cron cadence
- **Get webset monitor, webset item, research task** — Get a single Monitor's configuration, enabled/disabled status, cadence, and last/next run details
- **Create webset search, webset monitor, webset enrichment** — Run an additional search against an existing Exa Webset to discover more matching items without creating a brand-new webset
- **Enrichment cancel webset** — Cancel a running enrichment on a webset, stopping further per-item research
- **Webset cancel** — Cancel a running Exa Webset so it stops discovering new items
