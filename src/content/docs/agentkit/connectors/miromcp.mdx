## What you can do

Connect this agent connector to let your agent:

- **Update table, space, space role** — Update a Miro table widget's view: switch it to a grid table, timeline, or kanban board
- **Get table, diagram, canvas** — Get the history of a row's Latest Update field
- **Share space, board** — Grant a user or user group access to a space with a specific role
- **List space** — List the direct children of a space or section, one level deep
- **Create space, section, diagram** — Create a new Miro space
- **Delete section, code widget** — Delete a section
