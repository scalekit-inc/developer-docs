## What you can do

Connect this agent connector to let your agent:

- **File upload** — Upload a file to a Lokalise project for import, sending its content as a base64-encoded string alongside its filename and language code
- **Update webhook, translation, team user** — Update an existing webhook's URL, branch scope, subscribed events, or language mappings on a Lokalise project
- **Snapshot restore** — Restore a Lokalise snapshot into a new project, seeded with the snapshot's saved keys, translations, and settings, inside the same team as the original project
- **Group remove projects from, remove members from, add projects to** — Remove one or more projects from a user group in a Lokalise team, revoking the group's members' access to those projects
- **Secret regenerate webhook** — Regenerate the signing secret for an existing webhook on a Lokalise project
- **List webhooks, translations, translation providers** — List all webhooks configured on a Lokalise project
