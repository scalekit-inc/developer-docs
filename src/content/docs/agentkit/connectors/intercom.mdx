## What you can do

Connect this agent connector to let your agent:

- **Update company, visitor, ticket type attribute** — Update a single company using its Intercom-provisioned ID
- **Search activity logs, tickets, conversations** — Search admin activity logs with structured filters (date range, event types, pagination), distinct from the existing plain date-range list tool
- **Companies scroll** — Scroll over all companies in the workspace using Intercom's Scroll API, an efficient mechanism for iterating over large company datasets without the 10,000-record limit of the standard list endpoints
- **List office hours schedules, macros, external pages** — List all office-hours schedules configured for the workspace
- **Get macro** — Retrieve a single macro (saved reply) by its ID, subject to the same team-visibility rules as the Intercom inbox
- **Create office hours schedule, external page, data event summaries** — Create a new office-hours schedule defining the recurring weekly hours the workspace (or a team) is open
