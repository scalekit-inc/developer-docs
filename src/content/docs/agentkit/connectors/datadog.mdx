## What you can do

Connect this agent connector to let your agent:

- **Create user invitation, team, synthetics private location** — Send or resend a Datadog organization invitation email to an existing user
- **List teams, team memberships, slo correction** — List all Datadog teams, with optional keyword search and pagination
- **Update team, slo correction, metric tag configuration** — Update a Datadog team by ID
- **Remove team membership** — Remove a user from a Datadog team
- **Add team membership** — Add a user to a Datadog team
- **Get team, slo correction, synthetics browser test** — Get a specific Datadog team by ID
