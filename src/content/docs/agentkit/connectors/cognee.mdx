## What you can do

Connect this agent connector to let your agent:

- **Visualize records** — Generate a human-viewable HTML visualization of a dataset's knowledge graph — an interactive page with nodes and edges — distinct from Get dataset graph, which returns the raw node/edge JSON
- **Ingest skill** — Ingest a reusable skill from inline SKILL.md markdown text, without uploading a file
- **Entry remember** — Store a single typed memory entry directly into the session cache (or, for skill runs, the permanent graph), bypassing the bulk ingest+cognify flow used by Improve/Remember
- **History recall** — Get the authenticated user's history of prior recall (search) queries and results, each with id, text, user, and created_at
- **Delete ontology** — Delete an uploaded OWL ontology by its key, exactly as provided at upload time
- **List ontologies, datasets, dataset data** — List the OWL ontology files uploaded to this Cognee account
