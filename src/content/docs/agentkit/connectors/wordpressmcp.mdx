## What you can do

Connect this agent connector to let your agent:

- **Sites wpcom user** — List the authenticated user's accessible sites across WordPress.com and self-hosted Jetpack-connected sites
- **List wpcom plans, wpcom ai agent sites** — Use this to help users select or upgrade WordPress.com hosting
- **Management wpcom mcp user, wpcom mcp plugin** — Manage site collaborators on a WordPress.com site
- **Context wpcom mcp site editor** — Query site design context
- **Editing wpcom mcp site** — Read and modify site structure: templates, template parts, navigation menus (classic and block), global styles, and installed themes
- **Site wpcom mcp** — Manage site-level settings and infrastructure for a WordPress.com site — not content (use wpcom-mcp-content-authoring for posts, pages, media)
