## What you can do

Connect this agent connector to let your agent:

- **Interface validate scenario, scenarios** — Use this tool to validate a typed Scenario Interface before applying changes
- **List show scenarios, show executions, apps** — Renders an interactive UI in the chat — a searchable, folder-filterable, sortable list of the team's scenarios showing each scenario's status, used apps, and usage
- **Result show execution** — Renders a scenario execution’s outcome — status, outputs, and consumption — as an interactive widget in the chat, for a past or in-progress run
- **Update scenario-custom-properties, custom-apps, tools** — Update scenario custom properties data (scenario-custom-properties): Merge-update custom properties data for a scenario; only the specified items are changed
- **Replace scenario-custom-properties, data-store-records** — Replace scenario custom properties data (scenario-custom-properties): Replace all custom properties data for a scenario
- **Get scenario-custom-properties, tools, teams** — Get scenario custom properties data (scenario-custom-properties): Get the custom properties data filled in for a scenario
