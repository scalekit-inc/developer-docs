## What you can do

Connect this agent connector to let your agent:

- **Update automation, table, records for table** — Replaces the entire draft configuration (trigger, graph, name, description) of an existing
automation
- **Trigger test automation webhook** — Re-runs the trigger test for a genericWebhookReceived automation and waits briefly for a
newly captured payload schema
- **Form submit** — Submits a form, creating a new record in the form's source table
- **Search candidate linked records, records, bases** — Searches for records that are valid candidates for a linked-record (foreign-key) field,
returning each candidate's record ID along with the fields the linked-record field is
configured to display (the same fields shown on the in-product card)
- **Action revert** — Reverts a previous eligible Airtable mutation by performing the inverse write, using the actionId it returned
- **List views for table, external accounts, automations** — Lists the views in a table, returning each view's ID, name, and type
