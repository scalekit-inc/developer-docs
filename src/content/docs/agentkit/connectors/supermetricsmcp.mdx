## What you can do

Connect this agent connector to let your agent:

- **Guide supermetrics** — Explain what Supermetrics can do for this user, or show what has changed recently
- **Team manage user and** — Manage your Supermetrics account: get user profile, license, and team member info, invite new members, get a login link for a data source, or assign users to a subscription
- **Dashboards manage** — Upload, retrieve, edit, or view version history for live Supermetrics Studio dashboards that re-query data on each view
- **Manage resources** — Open the visual media picker or manage ad creative assets for a supported platform
- **Get today, async query results, campaign and resource** — Get the current UTC date and time
- **Discovery field, data source, accounts** — List available metrics and dimensions for a specific data source
