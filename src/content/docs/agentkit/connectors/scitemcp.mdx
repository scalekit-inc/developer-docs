## What you can do

Connect this agent connector to let your agent:

- **Update collection** — Update a DOI-list Collection the signed-in user can edit
- **Search patents, mhra, maude** — Search patent families from the scite patents database
- **Collection remove dois from, add dois to** — Remove DOIs from a Collection
- **Get mhra alert, maude report, grant** — Fetch the full text of a single MHRA alert or publication by document ID
- **Delete collection** — Permanently delete a Collection
- **Create collection** — Create a new Collection owned by the signed-in user
