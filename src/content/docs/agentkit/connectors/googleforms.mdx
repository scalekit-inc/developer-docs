## What you can do

Connect this agent connector to let your agent:

- **Settings set publish** — Update a Google Form's publish settings: whether the form is published and whether it is currently accepting responses
- **Watch renew** — Renew an existing watch on a Google Form for another seven days from now
- **List watches, responses** — List the watches configured on a Google Form
- **Delete watch** — Delete a watch from a Google Form, immediately stopping Pub/Sub notifications for that event type
- **Create watch, form** — Create a watch on a Google Form that publishes a Cloud Pub/Sub notification when the form's schema changes or a new response is submitted
- **Update batch** — Apply a batch of update requests to a Google Form in a single atomic call
