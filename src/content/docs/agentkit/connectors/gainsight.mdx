## What you can do

Connect this agent connector to let your agent:

- **Update task, object, goal** — Update one or more fields on an existing task in Gainsight Cockpit
- **List playbook, task, success plan** — List Playbooks configured in Gainsight Cockpit, optionally filtered by entity type, active status, and playbook type
- **Delete object** — Delete a single record from any standard or custom Gainsight MDA object by its GSID
- **Create object, goal, company** — Insert up to 50 records into any standard or custom Gainsight MDA object by name
- **Fetch goal** — Fetches/queries Customer Goal records in Gainsight
- **Query timeline, scorecard, relationships** — Search and filter Gainsight Timeline activity records by any field
