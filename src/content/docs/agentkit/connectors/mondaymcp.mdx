## What you can do

Connect this agent connector to let your agent:

- **Vibeupdate records** — Sends a follow-up message to modify an existing app
- **Vibepublication records** — Manage the publication state of a Vibe app on the caller account
- **Vibelist records** — List Vibe apps owned by the authenticated user
- **Vibeget records** — Fetch a Vibe app by id
- **Vibedelete records** — Delete a Vibe app and its associated assets
- **Vibecreate records** — Creates a new Vibe app from a natural-language prompt
