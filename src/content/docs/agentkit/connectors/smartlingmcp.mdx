## What you can do

Connect this agent connector to let your agent:

- **Update smartling** — Get detailed information about a specific Smartling job by its UID
- **Search smartling** — Search translation memory for similar translations in a Smartling project
- **Url smartling request upload** — Requests a short-lived URL for uploading a local file, for use with other tools that accept an "upload_id" parameter (e.g
- **Strings smartling remove tags from, smartling remove all tags from, smartling add tags to** — Remove tags from strings in a Smartling project
- **Job smartling remove strings from, smartling authorize, smartling add strings to** — Remove strings from an existing Smartling job by their hashcodes
- **Issue smartling open or close** — Open or close (resolve) an issue
