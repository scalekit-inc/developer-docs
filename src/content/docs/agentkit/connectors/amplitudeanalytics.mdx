## What you can do

Connect this agent connector to let your agent:

- **Search users** — Look up a user in Amplitude by Amplitude ID, Device ID, User ID, or a User ID prefix, via the Dashboard REST API's User Search endpoint
- **List lookup tables, user properties, user deletion jobs** — List all lookup tables configured in the project, via the current Lookup Table API 2 (/api/3/lookup_table)
- **Get lookup table, user composition, user activity** — Retrieve a single lookup table's metadata by name, via the current Lookup Table API 2 (/api/3/lookup_table/{name})
- **Delete lookup table, user property, event type** — Delete a lookup table via the current Lookup Table API 2 (/api/3/lookup_table/{name})
- **Cohort upload** — Create a new Amplitude behavioral cohort from an explicit list of user or Amplitude IDs, or update an existing cohort's membership list wholesale by passing existing_cohort_id
- **Update user property, group property, event type** — Partially update an existing user property in Amplitude's taxonomy
