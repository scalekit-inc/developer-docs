## What you can do

Connect this agent connector to let your agent:

- **Search ap** — Find piece triggers (the event that starts a flow) by natural-language description of when the flow should run (e.g
- **Read ap** — Read the full untruncated settings of any step, including the trigger: piece input, action/trigger name, loop items, router branches, and error handling options
- **Config ap validate step** — Validate a step configuration before applying it
- **Flow ap validate, ap test, ap rename** — Validate a flow for structural issues without publishing
- **Update ap** — Set or update the trigger for a flow
- **Step ap test, ap add** — Test a single step within a flow
