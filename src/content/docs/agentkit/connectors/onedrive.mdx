## What you can do

Connect this agent connector to let your agent:

- **Version restore item** — Restore a previous version of a OneDrive file, making it the current version
- **Item preview, unfollow drive, restore drive** — Get a short-lived, embeddable preview URL for a OneDrive file so it can be viewed in a browser (e.g
- **List items by path, delta, versions** — List the children (files and folders) of a folder in the signed-in user's personal OneDrive using its human-readable folder path instead of an item ID
- **Get special folder, permission, item by path** — Retrieve metadata for a well-known special folder in the signed-in user's OneDrive by its alias name, without needing to know its item ID
- **Drive download file in, copy item in** — Download the binary content of a file in a specific drive (e.g
- **File upload large, download, checkout** — Create a resumable upload session for uploading large files (greater than 4 MB) to OneDrive
