## What you can do

Connect this agent connector to let your agent:

- **Comment post document thread** — Post a new comment to an existing collaboration thread on a Lucid document
- **Update lucid** — Rename a Lucid folder or move it to a different parent
- **Feedback lucid submit** — Submit user feedback, a bug report, or a feature request about the Lucid MCP server to Lucid's product team
- **Library lucid shape** — Discover shapes/blocks available to insert into a Lucid document, by library, group, or search term
- **Details lucid shape** — Get default size, colors, and text-area/advanced properties for one or more Lucid shape classes
- **Search lucid** — Locate regions of a Lucid document that contain specific text, returning page/region indexes you can pass to lucidmcp_fetch
