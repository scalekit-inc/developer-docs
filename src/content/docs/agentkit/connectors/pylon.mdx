## What you can do

Connect this agent connector to let your agent:

- **Search users, tasks, surveys** — Search for Pylon users using a filter
- **List users, user roles, training data** — Returns all users (agents/teammates) for the organization, including their name, email, and role
- **Update user, team, task** — Update an existing Pylon user
- **Get user, training data, ticket form** — Retrieve a single Pylon user by their ID
- **Files training data upload** — Upload a single file as training data, either into a new training data container or an existing one
- **Content training data upload** — Upload plain text content as a training data document, either into a new training data container or an existing one
