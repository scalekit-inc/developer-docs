## What you can do

Connect this agent connector to let your agent:

- **List reference image, product set products, product set** — List the reference images attached to a Product Search product
- **Get reference image, product set, product** — Get a single reference image by its full resource name
- **Delete reference image, product set, product** — Permanently delete a reference image from a Product Search product; this removes only the Vision API's reference to the image and does not delete the underlying image file in Google Cloud Storage
- **Create reference image, product set, product** — Add a reference image to a Product Search product by pointing at an image file already stored in Google Cloud Storage
- **Update product, product set** — Update a product's display name, description, and/or labels in Google Cloud Vision Product Search via a partial update (PATCH)
- **Product set remove product, set add product** — Remove a product from a Google Cloud Vision product set, detaching it from that set's similarity-search scope
