## What you can do

Connect this agent connector to let your agent:

- **Answer upsert** — Create or replace the caller's answer to a customer question on a Google Business Profile location, using the legacy My Business API v4
- **Update question, notification settings, account admin** — Update the text of an existing customer question on a Google Business Profile location using the legacy My Business API v4
- **Search google locations, keywords, chains** — Search Google's existing Maps location data by free-text query (business name and address) before creating or claiming a new location
- **Insights report local post** — Get view and call-to-action click metrics for up to 100 local posts (What's New updates) on a single location, in one call, using the legacy My Business API v4
- **List questions, location verifications, invitations** — List the customer questions posted on a Google Business Profile location using the legacy My Business API v4
- **Get voice of merchant state, location google updated, chain** — Check whether a Google Business Profile location has 'Voice of Merchant' — meaning it is verified, not suspended, and eligible to have its edits reflected on Google Search and Maps
