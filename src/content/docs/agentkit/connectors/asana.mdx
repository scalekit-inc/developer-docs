## What you can do

Connect this agent connector to let your agent:

- **Update workspace, user, time tracking category** — Update the name of a workspace or organization
- **List workspace events, time tracking category entries, time periods** — Get all events that have occurred across a workspace domain since a sync token was created
- **Delete time tracking category, task template, rate** — Permanently delete a time tracking category
- **Create time tracking category, rate, organization export** — Create a new time tracking category in a workspace (e.g
- **Get time period, rate, organization export** — Get a single time period (e.g
- **Run rule trigger** — Trigger an Asana Rule programmatically for a task, passing action data the rule's action can use
