## What you can do

Connect this agent connector to let your agent:

- **Data set chart** — Repoint an existing chart at a new source data range and/or seriesBy setting
- **Table refresh pivot, sort, filter** — Refresh a single PivotTable's data from its source range, picking up any changes made to the underlying data since it was last refreshed
- **Tables refresh all pivot** — Refresh every PivotTable on a worksheet in one call, picking up any changes made to their underlying source data since they were last refreshed
- **List pivot tables, worksheets, tables** — List all PivotTables on a worksheet in an Excel workbook stored in OneDrive
- **Get used range, named item, chart image** — Retrieve the smallest range that contains any data or formatting on an Excel worksheet stored in OneDrive, without needing to already know the address
- **Delete named item, worksheet, table row** — Delete a named item (named range or named formula) definition from an Excel workbook stored in OneDrive
