## What you can do

Connect this agent connector to let your agent:

- **Send feedback** — Send feedback about the Brandfetch MCP server to the Brandfetch team
- **Get brand context, brand, asset base64** — Get LLM-ready brand context for a known domain — voice, audience, positioning, style
- **Transaction enrich** — Identify a merchant brand from a credit card or bank statement string
- **Urls build logo** — Construct Brandfetch Logo CDN URLs for one or more brands
- **Search brand** — Search for brands by name using Brandfetch's search index
