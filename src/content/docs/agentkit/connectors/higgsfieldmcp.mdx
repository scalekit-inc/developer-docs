## What you can do

Connect this agent connector to let your agent:

- **Status website, video analysis, tiktok publish** — Get the website's deploy status — the live URL and the status of the last deploy
- **Secrets website** — Manage a website's SECRETS (environment variables: API keys, tokens)
- **Access website repo** — Get direct git access to a website's repo to edit it — THE way to get the website's code
- **Db website** — Inspect the website's database (D1 / SQLite), READ-ONLY
- **Change voice** — Replace the spoken voice in a video with a different voice while keeping the original timing and visuals, then re-merge the new audio onto the video
- **Predictor virality** — Virality Predictor predicts a video's virality potential, engagement, attention, audience response, retention risk, hook strength, and creative performance with an interactive dashboard
