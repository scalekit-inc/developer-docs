## What you can do

Connect this agent connector to let your agent:

- **Status gdpr retrieval, gdpr deletion** — Check the status of a GDPR/CCPA data retrieval (Subject Access Request) previously created with 'mixpanelcompliance_gdpr_retrieval_create'
- **Create gdpr retrieval, gdpr deletion** — Create a GDPR or CCPA Subject Access Request (SAR) for one or more Mixpanel distinct_ids
- **Cancel gdpr deletion** — Cancel a pending GDPR/CCPA data deletion request before Mixpanel begins permanently erasing the data
