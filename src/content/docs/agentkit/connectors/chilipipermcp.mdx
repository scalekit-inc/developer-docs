## What you can do

Connect this agent connector to let your agent:

- **Update webhook, web experience, scheduling link** — Toggles a webhook's enabled state (pause or resume deliveries), matched by its (triggerType, url) identity
- **Secret webhook rotate** — Generates a new webhook signing secret for the tenant and returns it
- **List webhook, web experience, scheduling link** — Returns all webhooks configured for the tenant
- **Get webhook, web experience, meeting type** — Returns the tenant's webhook signing secret — the single key shared by all of the tenant's webhooks that signs every delivery
- **Delete webhook, web experience, team** — Unsubscribes a webhook, matched by its (triggerType, url) identity; deliveries for that subscription stop immediately
- **Create webhook, web experience, team** — Subscribes a url to a meeting lifecycle event (MeetingCreated | MeetingUpdated | MeetingDeleted); each firing delivers a signed POST to that absolute https url
